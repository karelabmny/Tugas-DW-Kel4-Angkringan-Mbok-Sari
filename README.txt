3. CARA MENJALANKAN
-----------------------------------------------------
1. Ekstrak file ZIP.
2. Buka folder project-kelompok.
3. Klik dua kali index.html. Website langsung terbuka di browser tanpa server atau konfigurasi tambahan.
4. Gunakan menu navigasi (Beranda, Profil, Galeri, Menu & Harga) untuk berpindah halaman.
5. Untuk menguji tampilan responsive, perkecil lebar jendela browser atau tekan F12 lalu pilih mode perangkat (device toolbar).


4. FITUR UTAMA
-----------------------------------------------------
HTML5: tag semantik (header, nav, main, section, article, aside, figure, footer), heading, paragraf,
       list (ul/ol), komentar, gambar dengan alt text, hyperlink internal/mailto/tel/eksternal,
       tabel (caption, thead, tbody, tfoot, colspan).
CSS3 : file eksternal, box model, Flexbox, embedded font (@font-face), variabel warna, media query
       untuk tampilan desktop, tablet, dan mobile.
